## Step 1: Using your IBMid or w3id

When going through the OAuth onboarding, you'll need to authenticate with your
IBMid (w3id for IBMers). If you don't have one,
[create an IBMid](https://www.ibm.com/account/reg/us-en/signup?formid=urx-19776).

## Step 2: Accessing the Carbon MCP cloud server

The Carbon MCP cloud server runs at `https://mcp.carbondesignsystem.com/mcp`.

Most agents support OAuth connectors. To connect, add the server URL as a remote
MCP server and sign in with your IBMid when your agent prompts you. For clients
that use a mcp.json config file, the minimal setup is:

```json
{
  "mcpServers": {
    "carbon-mcp": {
      "type": "streamable-http",
      "url": "https://mcp.carbondesignsystem.com/mcp",
      "oauth": true,
      "alwaysAllow": []
    }
  }
}
```

### Generate a token and session ID (if needed)

For clients that don't support OAuth discovery, use an auth token and session ID
instead. Carbon MCP still supports that method for anyone already set up that
way.

1. [Visit this link to generate a token and session ID](https://mcp.carbondesignsystem.com/mcp/auth/ibmid/web)
2. Copy your credentials to add to your Carbon MCP configuration

<AccordionItem title="Claude Desktop">

Carbon MCP can be set up in Claude Desktop as Custom Connector.

#### Adding Carbon MCP as a Custom Connector

- Open Settings > Connectors
- Click on Add Custom Connector
- When prompted for a name, enter `carbon-mcp`
- Under the Remote MCP server URL input, use
  `https://mcp.carbondesignsystem.com/mcp`
- Click Continue
- For Authentication radio button, select "Always required"
- For Oauth client, select "No client ID — register one automatically"
- Click Add
- If prompted by Claude Desktop to allow a connection to Carbon MCP, click "Allow"

## Step 4: Adding the carbon-builder skill

For best results with Carbon MCP, install the Carbon Builder skill. The source
is in this
[Github repo](https://github.com/carbon-design-system/carbon-mcp/tree/main/public/skills/carbon-builder).
This skill gives AI agents the Carbon-specific context they need to follow
Carbon conventions, use the right components, and produce consistent output.

Follow the instructions for the clients below.

<Accordion>
<AccordionItem title="Bob">

- Select the Bob `Advanced` mode, which is required to support skills.
- Download the
  [carbon-builder skill](https://github.com/carbon-design-system/carbon-mcp/raw/main/public/skills/carbon-builder.zip)
  and unzip it.
- Place the skill in `.bob/skills/` at your project root (project-scoped) or in
  `~/.bob/skills/` (global).

<br />

Bob reads `name` and `description` from `SKILL.md` to determine when to activate
the skill. The `references/` files are automatically available to Bob once the
skill is active. Verify the skill is visible by running `/list-skills` inside
Bob.

<br />

**Project-scoped (recommended for teams):**

<br />

_macOS / Linux_

```bash
mkdir -p /path/to/your-project/.bob/skills
cp -r carbon-builder /path/to/your-project/.bob/skills/
```

<br />

_Windows (PowerShell)_

```powershell
New-Item -ItemType Directory -Force -Path C:\path\to\your-project\.bob\skills
Copy-Item -Recurse carbon-builder C:\path\to\your-project\.bob\skills\
```

<br />

- Commit `.bob/skills/carbon-builder/` to your repository so the skill is shared
  across the team without each developer needing to install it separately.

<br />

**Global (available in all projects on this machine):**

<br />

_macOS / Linux_

```bash
mkdir -p ~/.bob/skills
cp -r carbon-builder ~/.bob/skills/
```

<br />

_Windows (PowerShell)_

```powershell
New-Item -ItemType Directory -Force -Path $HOME\.bob\skills
Copy-Item -Recurse carbon-builder $HOME\.bob\skills\
```

<br />

</AccordionItem>

<AccordionItem title="Cursor">

Cursor uses MDC-format rule files in `.cursor/rules/`.

<br />

- Download the
  [carbon-builder skill](https://github.com/carbon-design-system/carbon-mcp/raw/main/public/skills/carbon-builder.zip)
  and unzip it.

- Create the rules directory:

<br />

_macOS / Linux_

```bash
mkdir -p .cursor/rules
```

<br />

_Windows (PowerShell)_

```powershell
New-Item -ItemType Directory -Force -Path .cursor\rules
```

<br />

- Create `.cursor/rules/carbon-builder.mdc`:

<br />

```markdown
---
description:
  Carbon Design System expert — activate for Carbon components, Charts, IBM
  Products, AI Chat, and icons
alwaysApply: false
---

[paste the body of SKILL.md here — everything below the closing --- of the
frontmatter] [paste any reference file content from the references/ directory
you want included]
```

<br />

<div style={{ marginInline: '-1rem' }}>
  <InlineNotification kind="info">
    Cursor does not auto-load the <code>references/</code> directory. Inline the
    content of any reference files you need directly into the MDC file, or
    create additional <code>.mdc</code> rule files with{' '}
    <code>alwaysApply: false</code>.
  </InlineNotification>
</div>

<br />

Ensure carbon-mcp is configured as an MCP server in Cursor's settings.
